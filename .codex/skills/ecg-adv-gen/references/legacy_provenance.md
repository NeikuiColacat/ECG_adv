# Legacy ECG_adv_Gen Provenance

This reference keeps legacy material recoverable without loading it during
ordinary clean-room work.

The complete pre-simplification project Skill is frozen at repository commit
`5b117985089e78a503b47006c03a1a33b0aa3864`:

```bash
git show 5b117985089e78a503b47006c03a1a33b0aa3864:.codex/skills/ecg-adv-gen/SKILL.md
```

The legacy ECG_adv_Gen implementation is a read-only provenance oracle. Recover
historical code from commit `3a39a516420b52c219a782a7b7440f82746f4b90`
only when the user explicitly requests it.

Before using a historical item, label its date, repository, commit, mapping,
backbone, data split, and metric view. Old `/root` paths, removed scripts,
pre-v7 mappings, historical result tables, and old VAE-LHAT defaults are not
valid launch instructions or current evidence.

For current work, return to `AGENTS.md`, `configs/active_scripts.yaml`, and
`configs/active_evidence_registry.yaml`.
