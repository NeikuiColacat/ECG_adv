VAE Latent-Hull 在线对抗训练接入 ECG AugMix 方案

目标是在当前 real-anchor VAE Latent-Hull 在线对抗训练主线上，加入 ECG AugMix 的采集噪声和 corruption 一致性约束，判断增益来自目标中心真实样本、VAE latent-hull 对抗样本，还是来自 AugMix 鲁棒性正则。

生成日期：2026-05-23 主入口：scripts/pgd_cross_center/synth_online_at_super5.py AugMix：methods/augmix/ 输入：PTB-XL order, 100Hz, crop_len=1000 评估：PN2021 + PN2021-C

结论先行

推荐路线先做外层一致性

AugMix 不替代 VAE Latent-Hull。第一版把它作为外层训练的 JSD consistency regularizer，作用在 clean / AugMix view 之间。

不要先动内层 PGD避免归因混乱

内层仍保持 z_adv = (1-lambda)z0 + lambda * sum softmax(a_i) z_i。先不要在 PGD 目标里加入 AugMix view。

核心对照必须有 AugMix-only

需要单独跑直接目标中心微调 + AugMix。否则无法判断提升来自 VAE 对抗训练，还是普通 corruption consistency。

最稳的第一轮实验：在当前 VAE-only real-anchor Latent-Hull 主线基础上，默认传 --disable_quality_gate， 质量指标只记录不拦截样本；只对 PTB-XL source stream 和 target-real stream 加 AugMix JSD； adv buffer 暂时只走 clean BCE，不对被攻击样本再做强 corruption。

当前主线基线

目标中心 K=500 真实 ECG anchor，排除 eval ref ids
ECGTwin VAE encode/decode，latent 为 (B,4,128)
Latent-Hull PGD same-label convex hull，在线攻击当前 victim
质量监控与边界筛选 quality gate 关闭；Einthoven/HR/QRS 只记录，target prob window 可保留
混合训练流 PTB-XL + target real + roundtrip + adv buffer
PN2021 评估 ref-excluded，多中心 AUROC/AUPRC
已有训练流 当前作用 是否适合先加 AugMix 理由
PTB-XL source 保留源域判别能力，防止 target-only 过拟合 是 标签最干净，AugMix consistency 可以提升采集噪声鲁棒性，风险最低。
target_real 目标中心真实监督，是跨中心增益的主要 anchor 是 K=500 容易过拟合；轻度 AugMix 可以扩大局部邻域，但 severity 不能太高。
roundtrip VAE decode/encode 稳定性辅助 二期 它本身已经是生成链路样本，首轮先不增加变量。
adv buffer VAE latent-hull 在线对抗样本 二期 adv 样本已在边界附近，再强行 corruption 后用 hard label 监督，容易引入标签漂移。

AugMix 组件现状

仓库已有 ECG AugMix 基础设施，主要文件如下：

文件 职责 接入方式
methods/augmix/ecg_ops.py 5 个 ECG 算子，来自 DeepECG/fairseq-signals，并修正上游 bug。 不需要改；直接由 severity builder 调用。
methods/augmix/severity.py severity=1..10 到算子参数的线性映射。 训练期建议先用 2 或 3。
methods/augmix/augmix.py AugMix meta algorithm：Dirichlet chain 权重 + Beta clean/mix 权重。 训练循环里对 batch 内样本逐个调用。
methods/augmix/jsd_loss.py 多标签 Bernoulli JSD，一致性损失。 用于 logits_clean, logits_aug1, logits_aug2。
methods/augmix/dataset.py 把 base dataset 包成 clean/aug1/aug2/label。 当前 mixed stream 比较复杂，建议先在训练函数内在线生成，不直接套 Dataset。

5 个算子与 severity

算子 含义 severity=1 severity=10 训练期建议
powerline_noise 50/60Hz 工频噪声 max_amp 0.03 max_amp 0.30 可用；severity 2-4。
emg_noise 肌电/白噪声 max_amp 0.02 max_amp 0.20 可用；severity 2-3。
baseline_shift 阶梯型 DC 偏移 shift_ratio 0.05 shift_ratio 0.40 谨慎；首轮用 severity 2。
baseline_wander 低频基线漂移 max_amp 0.05 max_amp 0.40 可用；severity 2-4。
random_leads_masking 随机导联清零 mask_prob 0.05 mask_prob 0.50 首轮可关掉，或只在 PN2021-C 评估期用。
这里的 severity 是工程扰动强度，不是临床严重度标定。训练期用轻度扰动，测试期 PN2021-C 再扫公开 severity 1..5。

推荐训练目标

保持当前 VAE Latent-Hull 的内层攻击不变，只在外层 batch 训练时增加 AugMix JSD：

z_adv = (1 - lambda_hull) * z0 + lambda_hull * sum_i softmax(a_i) * z_i
L = L_masked_BCE(f(x), y) + lambda_aug * JSD_Bernoulli(f(x), f(A1(x)), f(A2(x))) + lambda_src * ||f(x_src)-f0(x_src)||^2 + lambda_ewa * ||theta-theta_anchor||^2
为什么先不把 AugMix 放进 PGD 内层

如果内层目标改成同时攻击 x_adv 和 AugMix(x_adv)，会让攻击更强，但也更难判断样本是否还在医学语义边界内。第一轮需要清楚归因。

为什么只在 clean 上做监督

AugMix view 保持标签不变只是近似。对 source/target real 可以接受；对 adv buffer 尤其危险。因此首轮用 clean BCE，AugMix view 只做一致性。

参数 首轮默认 说明
--augmix_streams ptbxl target_real 先只对源域和目标真实样本做 JSD；后续再加入 adv。
--augmix_severity 3 轻度到中度。若 PN2021 clean 掉点，退到 2。
--augmix_jsd_weight 4.0 比图像 AugMix 常见的 12 更保守，避免多标签 ECG 过强一致性。
--augmix_ops 先不含 random_leads_masking missing lead 会直接影响电压和导联形态，首轮留给评估或单独消融。
--augmix_adv_policy off 二期可改为 jsd_only，不要先对 AugMix 后的 adv 样本做 hard BCE。

2. 给 mixed stream 加 stream id

当前 ConcatDataset + WeightedRandomSampler 会丢失样本来自哪个 stream。要让 AugMix 只作用于指定 stream，建议加一个轻量 wrapper。

class StreamTaggedDataset(Dataset):
    def __init__(self, base, stream_id):
        self.base = base
        self.stream_id = stream_id

    def __len__(self):
        return len(self.base)

    def __getitem__(self, idx):
        x, y = self.base[idx]
        return x, y, self.stream_id

然后把 streams 从 (dataset, weight, per_sample_weight) 扩成 (dataset, weight, per_sample_weight, stream_name)，训练函数按 stream mask 决定是否生成 AugMix view。

3. 新增 batch 级 AugMix helper

from methods.augmix.augmix import augmix
from methods.augmix.jsd_loss import jsd_multilabel

def augmix_batch(x, cfg):
    # x: Tensor[B, 12, L]
    views = [
        augmix(sample.detach().cpu(), **cfg).to(x.device)
        for sample in x
    ]
    return torch.stack(views, dim=0)

说明：现有算子内部使用 numpy/random，首版放在 CPU 上最简单。确认有效后再考虑 GPU/vectorized 版本；当前 batch size 不宜开太大。

4. 新增 AugMix-aware 训练函数

logits_clean = model(signals)
bce = masked_bce(logits_clean, labels)

if use_augmix_for_this_batch:
    aug1 = augmix_batch(signals, augmix_cfg)
    aug2 = augmix_batch(signals, augmix_cfg)
    logits_aug1 = model(aug1)
    logits_aug2 = model(aug2)
    jsd = jsd_multilabel(logits_clean, logits_aug1, logits_aug2)
    loss = bce + augmix_jsd_weight * jsd
else:
    loss = bce
关键限制：不要对 labels == -1 的 masked sentinel 位置做监督；JSD 可以对 logits 全部类别做，因为它约束的是模型自身三路预测一致性。

实验矩阵

核心是把 “目标中心真实样本微调”、 “VAE Latent-Hull AT” 和 “AugMix consistency” 三个因素拆开。

实验臂 target real VAE Latent-Hull AugMix 目的
E0 direct-FT 有 无，--disable_adv_stream 无 判断 K=500 目标真实样本本身带来的增益。
E1 VAE-LHAT 有 有，当前主线 无 当前 VAE-only 主线基线。
E2 direct-FT + AugMix 有 无 source + target_real JSD 判断 AugMix 是否单独就能达到 VAE-LHAT 的提升。
E3 VAE-LHAT + AugMix v0 有 有 source + target_real JSD 第一主实验，测试两者是否互补。
E4 VAE-LHAT + AugMix adv-jsd 有 有 source + target_real + adv JSD 二期实验，只给 adv buffer 加一致性，不给 augmented adv hard label。
E5 linear-mix 有 有 x_mix=(1-rho)x_adv+rho A(x_adv) 最后再测真正的线性组合增强，避免一开始归因不清。

评价与归因规则

评价层 指标 判断标准
干净跨中心 PN2021 4-center / 7-center macro AUROC, macro AUPRC E3 必须超过 E1 或至少在弱中心提升；否则 AugMix 没有给 VAE 主线带来额外价值。
目标中心 ref-excluded 每个 center 的 AUROC/AUPRC 防止 K=500 reference 泄漏；所有 E0-E4 使用同一 ref 排除列表。
源域保持 PTB-XL fold10 AUROC/AUPRC 不能为了 PN2021 提升明显牺牲源域。必要时提高 source-logit anchor。
corruption 鲁棒性 PN2021-C absolute corrupted mean 和 self-clean drop 如果 corrupted absolute 提升但 drop 变大，只能说绝对 corrupted performance 更好，不能说鲁棒性更强。
类别层面 CD/HYP/MI/NORM/STTC per-class AUROC/AUPRC 特别检查 CD/HYP 是否被 baseline shift 或 lead masking 损害。
训练稳定性 JSD loss、masked BCE、ASR、quality metrics、buffer size JSD 快速变大或质量指标异常时，降 severity 或关闭 adv stream AugMix；hard quality gate 不参与样本筛选。

线性组合增强的二期方案

用户设想的 “latent hull 在线对抗训练 + AugMix 增强样本线性组合” 可以做，但建议放在 E5。

x_combo = (1 - rho) * x_adv + rho * A(x_adv), rho ~ Beta(alpha_combo, alpha_combo)
组合位置 实现 风险 建议
外层训练前 adv buffer push 后，训练 batch 中在线生成 x_combo adv 样本本来就在边界，corruption 后 hard label 可信度下降 只做 JSD 或 teacher-soft，不做 hard BCE。
内层攻击目标 PGD loss 同时包含 f(x_adv) 与 f(A(x_adv)) 攻击过强，可能优化出 corruption 特化样本 不进入第一版；等 E3/E4 证明有效后再测。
target real mix x_combo=(1-rho)x_real+rho A(x_real) 轻度风险，标签较可信 可以作为 E2 的增强版本，但要和 VAE 主线分开报。

失败模式与处理

  • PN2021 clean 掉点：把 augmix_severity 3 -> 2，augmix_jsd_weight 4 -> 2，并去掉 baseline_shift。
  • PTB-XL fold10 掉点：提高 source_logit_anchor_weight，或只对 target_real 做 AugMix，source 保持原样。
  • CD/HYP per-class 下降：关闭 random_leads_masking，降低 baseline_shift，保留 powerline/emg/wander。
  • 训练变慢：AugMix 当前按样本 CPU 调用，先减 batch size；确认有效后再做 GPU/vectorized 实现。
  • adv buffer 质量指标变差：不要在内层 PGD 加 AugMix；先只对 real streams 加 JSD。hard quality gate 默认关闭，只记录异常用于回溯。

  1. 给 synth_online_at_super5.py 加 stream id wrapper 和 AugMix CLI，但默认关闭，保证旧命令完全兼容。

一句话论文表述

推荐写法：ECG AugMix 被用作采集噪声一致性正则，补充 ECGTwin VAE latent-hull 的形态/中心域 manifold augmentation； 通过 direct-FT、direct-FT+AugMix、VAE-LHAT、VAE-LHAT+AugMix 四臂对照，区分目标中心真实样本、VAE latent 对抗训练和 corruption consistency 的独立贡献。
