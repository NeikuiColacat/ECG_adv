VAE-only 主线尝试：哪些方法有效，提升来自哪里

这份页面把过去约 24 小时围绕 ECGTwin VAE latent space 的 real-anchor / latent-hull online AT 尝试合并成一页。 重点区分“VAE-only adversarial stream 的独立贡献”和“目标中心真实样本适配”的贡献，避免把强基线带来的提升误归因给 VAE。

一句话结论

VAE-only real-anchor latent-hull 是一个有效的 on-manifold adversarial regularizer； 在 EfficientNet 和多个 PTB-XL benchmark backbone 上稳定正向，但幅度中等。 在 ECGFounder 上，最强正向证据来自 official full fine-tuning + K=100 fixed short-horizon， 但 K=500 和 frozen residual adapter 的大提升主要来自 target-real adaptation，不是 VAE 独立贡献。

应该保留的论文主张

保守主张： VAE-only real-anchor latent-hull online AT 可以作为目标中心真实样本的 on-manifold adversarial regularization， 在多个 backbone 与多个中心上提升外部中心 AUPRC，尤其是 CPSC。

现在不能过度声明的点

不要写成： ECGFounder 上的大幅 target gain 全部来自 VAE-only。K=500 和 frozen residual adapter 审计显示， 主要驱动是 target-center real adapter / full fine-tuning，VAE 只在 K=100 的短程 refinement 中有较清晰增量。

当前最有效方案与 Takeaway

补充截至 2026-05-25 的 v6 映射探索结论

最适合作为主方法的版本：EfficientNet1DV2 + target-real VAE Latent-Hull online AT

当前最干净的主方法证据来自 EfficientNet1DV2：先用每个目标中心随机 K=500 真实 ECG 做直接微调， 再从这个 direct-K500 checkpoint 继续加入 ECGTwin VAE latent-hull online adversarial training。 最强独立候选是 compatsoft direct-init latent-mixed-teacher / anchor-soft 这一族。

口径 Direct K500 Best VAE-family VAE 增量
EfficientNet1DV2 四中心均值 0.8543 / 0.4880 0.8722 / 0.5148 +1.79 / +2.68pp
drop-all-zero sensitivity - 0.9018 / 0.6776 用于检查全零样本影响

这个结果比 ECGFounder 更适合作为“VAE 带来额外贡献”的主证据，因为它和同 backbone 的 direct K500 微调做了匹配对照， VAE-family 相对 direct K500 仍有约 1.8pp AUROC / 2.7pp AUPRC 的净提升。

最强数字但归因更复杂：ECGFounder selector

ECGFounder 当前最高四中心结果是 K500-internal classwise selector： 0.9198 / 0.6435。 它相对 frozen/head direct K500 是 +1.56 / +4.67pp， 相对 init-head direct fullFT 是 +0.62 / +1.30pp。

归因边界： ECGFounder 的大部分增益来自 K500 supervised adaptation、head initialization 和 full fine-tuning recipe； VAE online AT 是有用的 refinement / candidate diversity，但不能写成唯一主因。

发现 1：Direct K500 是强基线

目标中心 500 条真实样本本身已经能解释很多跨中心提升。所有论文主表必须和同 backbone、同 K、同 split 的 direct K500 微调比较。

发现 2：VAE 更像正则器

当前 VAE 的有效角色不是“凭空生成大量新疾病样本”，而是围绕目标中心真实 ECG anchor 在 VAE manifold 上制造边界附近样本， 作为 on-manifold adversarial regularization。

发现 3：攻击不能只追强

单纯提高 adversarial weight 或 PGD 强度并不会稳定提升；过强会伤 Georgia / Ningbo，过弱则没有边界压力。 后续需要记录 atk_init、atk_anchor、loss_gain 和 ASR。

发现 4：局部同标签 latent 更稳

same-label / compatible local latent hull 比盲目跨类混合更可信；source-partner、label-mode-only、selector 扩池都没有突破当前 ceiling。

发现 5：质量 gate 不是主轴

复杂 victim-score quality gate 没有带来稳定收益。主线只保留硬拒绝：NaN/Inf、flatline、严重幅值异常和明显物理无效 decode。

发现 6：不能按测试分布特调

探索阶段可以看 held-out 反馈，但最终方法只能用随机 K500 子集及其内部验证、源域 source floor 和固定全局 recipe 选模型。

应该写进主方法的技术细节

  1. 固定每个目标中心随机 K=500；K500 ref ids 从最终目标中心评估中排除。
  2. 将目标中心真实 ECG 编码到 ECGTwin VAE latent；decode 后做 lead reorder，并送入 100Hz / 1000 点 EfficientNet1DV2 pipeline。
  3. 在标准化 latent 空间中找 same-label 或 compatible local partners；混合时 include-anchor，避免远距离全局随机混合。
  4. 使用 anchor-dominant latent hull：保留原始真实 anchor 的主导权，hull_lambda 维持在 0.05-0.15 的低到中等范围。
  5. 在线 PGD 只在 latent hull 内搜索边界样本，decode 后进入训练流；不要使用 ECGTwin DiT 直接 synthetic 作为主因果证据。
  6. adv label 优先使用 multi-hot preserving 的 latent_mixed_teacher / anchor-soft 形式，避免把多标签 anchor 简化成 argmax 单标签。

主训练与选择规则

  1. 训练 loss 同时保留 source / target clean BCE、latent mixed BCE、adversarial BCE 或 Bernoulli-KL，以及必要的 source-logit anchor。
  2. adversarial pressure 采用 warmup 或低到中等强度；目标 ASR 是有边界压力但不破坏 clean/source，约 30-70% 更合理。
  3. checkpoint 选择用 K500 内部 validation 加 source clean floor；禁止用完整目标中心测试集类别分布或 held-out oracle 选超参。
  4. 主报告同时给 all-zero kept、drop-all-zero、per-center、per-class，并明确 PN2021 Super5 mapping version。
  5. ECGFounder 作为强 foundation-model extension 报告：强调 VAE 对 matched direct/fullFT 的小幅增量和 selector diversity，而不是把全部提升归因给 VAE。

共同评估协议

把旧机器结果放到同一把尺子上看
1

数据与标签

PTB-XL Super5 源域训练，PN2021 四个目标中心评估：ningbo、chapman_shaoxing、cpsc_2018、georgia。PN2021 使用 v5 strict mapping：v5_super5_strict_voltage_pacing_suppress_20260522。

2

目标中心样本排除

每个 target-center adaptation 使用 K 个目标中心真实 ECG anchor；评估同一个中心时排除这些 ref ids，避免测试污染。

3

VAE-only 定义

不使用 ECGTwin DiT 直接合成样本，不使用 center token。只用目标中心真实 ECG 经 ECGTwin VAE 得到的 latent，在 same-label latent hull 内做 online adversarial search，再 decode 回 ECG 参与训练。

4

两个口径

all-zero kept 是主指标；drop-all-zero 是敏感性分析，检查提升是否只是大量 Super5 全 0 样本造成。

Latent-Hull 形式

z_mix = sum softmax(a_i) * z_i

z_adv = (1 - lambda) * z0 + lambda * z_mix

旧机器主线常用 M=20, lambda=0.15, hull_steps=3 或 10。真实 target anchor 是 ECGTwin VAE latent，不是 DiT synthetic candidate。

负结果与边界

这些是后续写论文时最容易误写的地方

ECGFounder frozen adapter 的大 gain 不能归因给 VAE

K=500 real-only adapter 与 VAE-only adapter 基本持平，说明 target-center real adapter 是主驱动。

real-only 0.9120 / 0.6357 vs VAE-only 0.9082 / 0.6354。

pure VAE-only 是弱正向

不喂 target-real supervised stream 时，ECGFounder 与 EfficientNet 都只有 0.2-0.6pp 级别增益。

可作为独立性证据，但不能支撑“明显强于 real-only”。

低 K 不稳定

ECGFounder full-FT fixed horizon 下，K=20/50 多数中心不稳定，K=100 才出现 4/4 AUPRC 正向。

当前不能宣称“几十条目标样本就稳定足够”。

Georgia 是敏感中心

较高 adv weight 会伤 Georgia，低权重或 fixed short-horizon 才能修复一部分。

后续应避免一套 adv_weight 硬套所有中心。

目标 AUPRC 未普遍达到 PTB-XL source

CPSC drop-all-zero 在部分设置接近或超过 source；Ningbo/Chapman/Georgia 仍明显低于 source AUPRC。

可写“保源同时提升目标中心”，不要写“全面达到同源性能”。

checkpoint selection 影响很大

fold9-only、target-val、last_epoch 得出的 target 表现不同。fixed epoch=1 目前更简单稳定。

后续主表需要固定 non-leak selection 规则。

建议后续主线

把可用结果变成论文叙事

论文叙事建议

  1. 主方法写成 target-center real ECG anchors + ECGTwin VAE latent-hull online AT，不是直接 ECGTwin DiT synthetic augmentation。
  2. EfficientNet 和 5 个 benchmark backbone 证明机制不是单模型 artifact。
  3. ECGFounder official full-FT K=100 fixed short-horizon 作为强基线上的 refinement 证据。
  4. 明确报告 negative evidence：real-only adapter 是强 baseline；VAE 的独立贡献是 regularization/refinement，不是所有提升的唯一来源。

下一轮实验优先级

  1. ECGFounder full-FT K=100 fixed epoch=1 做多 seed 复现。
  2. 固定 no-VAE vs VAE aw5/aw20 的选择规则，不使用 target test oracle。
  3. EfficientNet1DV2 若继续追，应做 last-block/full fine-tune 对照；head adapter 已经显示增益太小。
  4. 所有主表同时报告 all-zero kept 与 drop-all-zero，并保留每中心、每类分析。
