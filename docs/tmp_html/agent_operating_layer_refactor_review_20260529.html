Agent Operating Layer Refactor Review

ECG_adv_Gen repo state review, subagent synthesis, and next refactor decision. Date: 2026-05-29.

Decision

The highest-value next refactor is not a broad split of the 2000+ line online-AT trainer. The highest-value step is to close the evidence traceability gap around the trusted VAE-LHAT v7 mainline, then make that traceability enforceable by CPU-only audit.

This round implements that direction: VAE-LHAT now has a legacy backfilled manifest path, the audit treats trusted mainline missing manifests as errors, and resume no longer overwrites best_model.pt before loading a checkpoint.

Subagent Review Summary

Experiment Auditor

P0 gap

VAE-LHAT v7 metrics were trusted, but the method had no run-level manifest. Direct had a managed manifest, while VAE only had per-center legacy artifacts.

Training Reviewer

P1 risk

Resume loaded after an initial save of best_model.pt, so a resumed job could overwrite the previous best before the checkpoint state was restored.

Repo Mapper

P2 organization

The repo needs a single agent-facing page that maps AGENTS, registry, active scripts, configs, evidence bundles, and do-not-commit paths.

What Changed In The Repo

  • Added a backfill module for legacy VAE-LHAT manifests under ecg_adv_gen/evidence/backfill.py.
  • Added CLI scripts/agent/backfill_vae_lhat_manifest.py.
  • Updated the active registry to point VAE-LHAT at run_manifest.backfilled.json.
  • Strengthened the registry audit so trusted mainline methods without manifests fail audit.
  • Changed VAE-AT resume flow so fresh runs save an initial best model, but resume does not overwrite the prior best before loading checkpoint state.
  • Added critical args contract validation for resume, with --allow_resume_config_drift reserved for intentional recovery.
