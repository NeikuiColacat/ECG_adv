# VAE500 Old-Recipe K500 Check

Date: 2026-06-01

## Purpose

核查 500Hz VAE online AT 失效是否只是新 recipe 太保守。该实验把 500Hz
VAE500 训练参数尽量拉回旧 100Hz 强路线：

```text
backbone: EfficientNet1DV2 500Hz
mapping: v7_super5_sjr_rgq_review_20260528
K: 500 target-center real anchors
eval: PN2021 target-center ref-excluded heldout
classes_in_scope: NORM, MI, STTC
hull_M: 10
hull_lambda: 0.15
hull_steps: 5
K_anchor: 300
adv_label_mode: mixed_soft
adv_teacher_mix: 0.3
target_real_weight: 40
adv_weight: 0.06
quality gate: enabled
roundtrip_anchor_n: requested 1500, automatically disabled for VAE500 backend
```

Run root:

```text
/root/autodl-tmp/vae500_oldrecipe_k500_v7_20260601
```

Compared with the previous plain VAE500 K500 recipe, old-recipe produces much
stronger adversarial pressure. The earlier plain recipe had `loss_gain` around
`3e-4` to `5e-4`; this run reaches around `1e-2` to `5e-2` on several centers.

## Anchor Label Issue

The old trusted scope `NORM/MI/STTC` no longer matches v7 K500 label
distribution well:

| center | CD | HYP | MI | NORM | STTC |
|---|---:|---:|---:|---:|---:|
| ningbo | 102 | 130 | 5 | 120 | 278 |
| chapman_shaoxing | 105 | 120 | 4 | 119 | 253 |
| cpsc_2018 | 295 | 0 | 0 | 97 | 110 |
| georgia | 128 | 121 | 1 | 101 | 300 |

Under v7, MI is almost absent in K500 for three centers and absent in CPSC.
Therefore the old `NORM/MI/STTC` scope effectively becomes mostly `NORM/STTC`
for CPSC/Georgia and cannot exploit abundant CD/HYP anchors.

## Interpretation

This experiment weakens the simple claim that "500Hz VAE does not work."
The 500Hz VAE can generate valid adversarial pressure and gives a meaningful
single-center gain on CPSC:

```text
cpsc_2018: +1.38pp AUROC / +2.09pp AUPRC over matched direct K500
```

However, the four-center mean gain is only:

```text
+0.42pp AUROC / +0.56pp AUPRC
```

So the current old-recipe check does not satisfy the global goal.

## Next Decision

Run one v7-aware old-recipe variant:

```text
classes_in_scope: CD, HYP, NORM, STTC
allow_hyp_cd_trust: true
same old-recipe pressure:
  hull_lambda=0.15
  K_anchor=300
  mixed_soft teacher_mix=0.3
  target_real_weight=40
  adv_weight=0.06
  quality gate enabled
```

Rationale: v7 K500 anchors are rich in CD/HYP and sparse in MI. If the VAE500
branch is useful for v7, it should exploit the actual v7-positive classes
instead of preserving the older NORM/MI/STTC trust scope.
