四中心方法对比阶段结果

本报告汇总截至 2026-05-17 已完成的 PTB-XL → PN2021 四目标中心方法对比。除 foundation model 外，所有 EfficientNet 系列方法都使用同一个 PTB-XL Super5 EfficientNet1DV2 初始化和 minimal_resample + 100Hz 10s + per_sample_global 协议；目标中心适配后的评估均排除 K=500 ref ECG，避免测试污染。

当前结论：在相同 EfficientNet backbone 下，普通 K-shot fine-tuning、Mixup、Manifold Mixup、SAM、input-space FGSM/PGD-AT、MixStyle、GroupDRO proxy、AdaBN、TENT、EATA-lite、CoTTA-lite、SHOT-style、Deep CORAL、DANN、CDAN 都没有追上我们的 VAE real-anchor latent-hull AT。外部大规模 foundation encoder 中，ECG-FM、ST-MEM、MERL ResNet18 的 frozen linear probe / K500 head fine-tuning 也没有超过我们；真正超过我们的仍是 ECGFounder 加 K-shot 线性头微调，这应作为强外部表征 baseline，而不是同类轻量适配方法。

6. 后续优先级

同 backbone 维度下，SHOT/EATA/CoTTA-lite/MixStyle/GroupDRO proxy 和 input-space FGSM/PGD-AT 已完成且未超过 LH-AT。foundation model 维度下，ECG-FM、ST-MEM、MERL ResNet18 frozen LP / K500 head FT 已完成且低于 LH-AT；ECGFounder K-shot head FT 是当前唯一稳定超过我们 target AUPRC 的外部表征路线。PCLR/CLOCS 这类 ECG 自监督仓库只有在官方权重和 12-lead 输入协议可快速对齐时才值得跑全量。
