# PTB-XL Train2000 German Report To ECGTwin Prompts

Date: 2026-05-03

## Goal

Convert the seed42 graduate-project PTB-XL train2000 records' original
`report` field into ECGTwin-compatible English prompt fragments.

ECGTwin-compatible means concise English ECG report fragments separated by `|`,
for example:

```text
sinus rhythm|normal ecg
inferior myocardial infarction
left bundle branch block
myocardial infarction|st elevation
```

## Inputs

```text
PTB-XL metadata:
  /root/autodl-tmp/ptbxl/ptbxl_database.csv

Split:
  /root/autodl-tmp/graduate_project/splits/ptbxl_super5_seed42_train2000_val2000.json

SCP statements:
  /root/autodl-tmp/ptbxl/scp_statements.csv
```

Relevant PTB-XL columns:

```text
report
scp_codes
initial_autogenerated_report
```

The field used here is `report`.

## Implementation

Script:

```text
scripts/ecgtwin_gen/translate_ptbxl_reports_to_ecgtwin_prompts.py
```

Output:

```text
/root/autodl-tmp/graduate_project/ptbxl_train2000_ecgtwin_prompts_seed42.jsonl
```

The converter is local-only and deterministic. It does not call an external
translation API. It combines:

```text
1. German/English report phrase rules
2. SCP code -> scp_statements.csv English descriptions
3. super5 class fallback if both fail
```

## Coverage

```text
records = 2000
german_report_rules + scp_codes = 1939
scp_codes only = 61
```

## Caveat

This is not a certified clinical translation. It is a reproducible experiment
prompt compiler for ECGTwin. For thesis-grade claims, treat these translated
prompts as an ablation and validate with generation quality, class consistency,
and downstream AUROC/AUPRC before claiming improvement.
