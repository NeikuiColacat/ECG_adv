一页速览

五个算子覆盖 ECG 采集和传输中常见的噪声、漂移、位移和导联缺失。除导联 mask 外，其余算子主要改变信号形态或噪声结构； 它们用于评估模型面对非理想输入时是否保持分类稳定。

算子 模拟对象 主要视觉特征 鲁棒性含义
powerline_noise 50/60 Hz 电源工频干扰。 全局周期性高频纹理叠加，细小波形边缘变粗。 测试模型是否过度依赖高频细节，尤其是 ST/T 细节附近的抗干扰能力。
emg_noise 肌电噪声和体表电极附近的随机高频扰动。 逐导联随机毛刺和白噪声，局部尖峰更密。 测试模型对随机高频噪声的稳定性，避免把肌电噪声误当成异常波形。
baseline_wander 呼吸、体动、电极接触变化导致的低频基线漂移。 整段波形随时间缓慢上下摆动，等电位线不再平直。 测试模型是否依赖绝对基线位置，以及 ST 段判断是否会被低频漂移扰乱。
baseline_shift 电极接触突变或设备饱和恢复造成的片段式 DC 偏移。 某些时间段整体跳到另一条水平线，形成阶梯状偏移。 测试模型面对局部基线突变时是否仍能利用其余有效片段。
random_leads_masking 导联脱落、接触不良或通道记录失败。 随机导联被清零，信息直接缺失。 测试模型是否能从剩余导联恢复诊断线索，是最接近输入缺失的压力项。

Clean vs 增强结果

每节左侧为同一条 clean ECG，右侧为对应单算子增强后的 ECG。标题中的 drop 数字来自旧报告中 CPSC direct K500 的每算子下降视图，用于帮助判断该扰动对模型的相对压力。

Operator 1

Powerline noise

powerline_noise · seed 20260615 · diff RMS 7.689 · max |diff| 7.689

EffNet direct: drop 7.34 / 9.71 pp ECGFounder direct: drop 12.17 / 15.33 pp
它在模拟什么
电网交流电耦合进 ECG 采集链路，形成 50 Hz 或 60 Hz 的周期性正弦干扰。
波形上怎么看
所有导联都会出现规律的细密振荡，QRS、ST 段和 T 波边缘被高频纹理覆盖。
为什么纳入评估
STTC 类别依赖细节形态，工频干扰能暴露模型是否把高频纹理当成诊断证据。
周期性噪声高频干扰采集环境问题
Operator 2

EMG noise

emg_noise · seed 20260616 · diff RMS 1.321 · max |diff| 7.602

EffNet direct: drop 4.73 / 5.86 pp ECGFounder direct: drop 10.39 / 14.71 pp
它在模拟什么
肌肉活动、电极附近运动和皮肤接触变化带来的随机高频肌电噪声。
波形上怎么看
不是规则正弦，而是更随机的毛刺、抖动和局部尖峰；不同导联噪声强弱可不同。
为什么纳入评估
它检验模型能否从 noisy ECG 中保留 QRS/ST/T 的主要结构，而不是被随机尖峰牵引。
随机噪声肌电干扰逐导联扰动
Operator 3

Baseline wander

baseline_wander · seed 20260617 · diff RMS 2.407 · max |diff| 8.467

EffNet direct: drop 13.08 / 14.56 pp ECGFounder direct: drop 1.38 / 4.08 pp
它在模拟什么
呼吸、体动、电极阻抗变化造成的低频基线漂移；实现上用多个低频余弦叠加。
波形上怎么看
整条 ECG 的等电位线随时间缓慢上下摆动，T 波和 ST 段的相对高度更难判断。
为什么纳入评估
它直接挑战 ST 段和 T 波相关诊断，因为模型需要区分真实 ST/T 改变和低频基线漂移。
低频漂移呼吸/体动ST 段敏感
Operator 4

Baseline shift

baseline_shift · seed 20260618 · diff RMS 1.012 · max |diff| 1.161

EffNet direct: drop 7.06 / 9.33 pp ECGFounder direct: drop 0.26 / 0.67 pp
它在模拟什么
电极接触瞬时变化、放大器恢复或局部饱和造成的片段式 DC 偏移。
波形上怎么看
不是平滑漂移，而是某些时间段整体跳到另一个水平位置，形成阶梯状基线变化。
为什么纳入评估
它检验模型能否忽略局部片段的绝对电位偏移，并从未受影响的导联和时间段恢复判断。
局部偏移阶梯基线设备/接触问题
Operator 5

Random leads masking

random_leads_masking · seed 20260619 · diff RMS 0.799 · max |diff| 13.619

EffNet direct: drop 7.71 / 10.92 pp ECGFounder direct: drop 5.31 / 10.25 pp
它在模拟什么
导联脱落、接触不良或通道记录失败，导致部分导联信息完全缺失。
波形上怎么看
若干导联直接变成平线；这不是噪声变大，而是有效诊断信息被删除。
为什么纳入评估
它测试模型能否利用剩余导联的冗余信息。对依赖特定导联模式的类别，这通常是强压力项。
导联缺失平线信息删除

解释边界

  • 这些图片是鲁棒性评测用的 corruption/augmentation 示例，不是要声称增强后 ECG 仍然适合临床人工诊断。
  • calibrated_10to20pp severity 5 是为模型压力测试校准的强扰动，强度大于训练时温和 AugMix 的默认强度。
  • 同一张 clean ECG 被重复用于五个对照，目的是让算子差异更容易比较，而不是展示数据集总体分布。
