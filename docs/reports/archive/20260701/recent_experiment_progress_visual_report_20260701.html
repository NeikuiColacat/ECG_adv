当前方法进度判断

主线仍然是 VAE-LHAT + locked three-chain AugMix：target-center real anchors 进入 ECGTwin VAE latent hull， 第三链提供 VAE-LH adversarial waveform，另外两链提供 official corruption chain，训练时把 hard-sample 能力写进分类器参数。
目前还不能写成最终结论：EffNet 和 ECGFounder 都能超过 corrupted-K500 supervised baseline， 但 ECGFounder 还缺 matched noAug、raw noVAE、LoRA/训练范围 ablation 和 paper-grade run records。
