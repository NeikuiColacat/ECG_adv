一、数据流总览

1. 配置入口 YAML + local paths 生成受管命令。
2. 数据与标签 PTB-XL / PN2021 波形映射到 Super5。
3. 预处理缓存 100Hz/1000 点 EfficientNet 输入，必要时 ECGFounder 5000 点输入。
4. K500 ref 每中心 K=500 target anchors，并在最终 eval 排除。
5. 训练/适配 Direct K500 baseline 与 VAE-LHAT candidate。
6. 评估/归档 PN2021 clean、PN2021-C robustness、metrics_long、paper tables。
人工审核的核心问题：每一阶段的输出是否被下一阶段按同一个 mapping、同一个 K500 ref-exclusion、同一个 shape/rate/lead-order 协议消费。 一旦某阶段偷偷换了路径、标签版本、ref_meta 或评估视图，后面的 AUROC/AUPRC 表就不再可比。
