2. PTB-XL -> Super5 当前策略

PTB-XL 是 Super5 训练标签的 source of truth。当前代码位于 scripts/triple_labels/label_schemes.py，函数为 ptbxl_scp_to_super5()。 

CLASS_NAMES_SUPER5 = ["CD", "HYP", "MI", "NORM", "STTC"]
confidence_threshold = 0.0
if conf >= confidence_threshold and code in scp_to_super5:
    label[super5_class] = 1.0
规则项 当前选择 原因 是否建议改
SCP 来源 只使用 scp_statements.csv 中 diagnostic == 1 的 statement 匹配 PTB-XL 官方 diagnostic superclass 定义 不改
likelihood/confidence conf >= 0.0，即 key 存在即参与聚合 接近 PTB-XL 官方示例聚合方式；当前全量类别计数与官方分布一致 不静默修改；若尝试 conf > 0 必须作为新标签版本
无 diagnostic superclass 样本 保留为 all-zero label 当前 EfficientNetV2 baseline 就是按此训练；全量约 411 条 可做过滤消融，但不能直接替换主结果

3. PN2021 -> Super5 当前 v3 策略

当前 PN2021 映射版本为 v3_super5_normsuppress_20260501， hash 为 544ed42dee6d。核心思想是：只把明确异常 SNOMED 映射到 CD/HYP/MI/STTC；只把 strict sinus rhythm 作为 NORM 候选； 节律、轴偏、早搏、低电压、边界形态等只取消 NORM，不强行变成 Super5 阳性。 

if any(CD, HYP, MI, STTC) == 1 or any(code in NORM_SUPPRESS_SNOMEDS):
    NORM = 0
elif sinus rhythm is present:
    NORM = 1
else:
    NORM = 0
集合 数量 含义
SNOMED_TO_SUPER5_POSITIVE 52 直接映射到异常类：CD 23、STTC 12、HYP 10、MI 7
NORM_POSITIVE_SNOMEDS 1 当前只接受 strict sinus rhythm 作为 NORM 候选
NORM_SUPPRESS_SNOMEDS 34 AF/AFL、PAC/PVC、axis deviation、low voltage、Q wave abnormal、early repolarization 等

4. 当前高风险映射点

项目 当前 v3 策略 主要风险 改进方向
Q wave abnormal suppress-only Q wave 可能提示既往 MI，但也不是 PTB-XL STTC 的严格等价项 主规则保持 suppress-only；做 QAb -> MI 和 QAb -> STTC 敏感性实验
early repolarization suppress-only 可能是良性变异，直接放 STTC 容易过强 主规则保持 suppress-only；只在 broad STTC ablation 中测试
pacing rhythm / pacing pattern CD positive PTB-XL CD 子类未必有完全等价 pacemaker 类 建议 main v4 改为 suppress-only；保留 pacing -> CD 作为敏感性版本
left ventricular high voltage / right atrial high voltage HYP positive 高电压不等于结构性肥厚，可能高估 HYP 阳性 建议 main v4 改为 suppress-only；保留 high voltage -> HYP 作为敏感性版本
sinus brady/tach/arrhythmia suppress NORM 可能是生理变异，但也不等价于 PTB-XL diagnostic NORM 主规则保持 suppress；做宽松 NORM-compatible ablation
ischemia STTC positive SNOMED ischemia 不是单纯 ECG ST/T 形态，但比映射到 MI 更稳 主规则保留 STTC；论文解释为 ECG/diagnostic semantic projection

5. 现有改进方案

方案 A：PN2021 v4-strict 主映射

推荐作为下一版主线。目标是减少容易被审稿人质疑的“过强阳性映射”，让主结果更保守。

改动 具体规则 预期影响
pacing 从 CD 移出 pacing rhythm / atrial pacing / ventricular pacing 改为 suppress-only CD 阳性减少，CD AUPRC 可能变化；更保守
high voltage 从 HYP 移出 LV high voltage / RA high voltage 改为 suppress-only HYP 阳性减少，避免把 voltage-only 当结构性肥厚
保留严格 NORM 只有 sinus rhythm 且无 abnormal/suppress code 时 NORM=1 避免 PN2021 中 sinus rhythm 与异常诊断共存造成 NORM 污染
保留 Q wave / early repol suppress-only 不直接产生 MI/STTC 阳性 避免边界码主结果过强

方案 B：PN2021 sensitivity ablation 映射族

用于回答审稿人“你的 SNOMED -> Super5 投影是否影响结论”的问题。每个版本都要生成新的 cache version/hash，并重跑 baseline 与在线对抗训练模型。

版本 规则 用途
v4_strict pacing/high-voltage suppress-only；Q wave/early repol suppress-only；strict NORM 推荐主结果
v4_broad_cd_hyp pacing -> CD；high-voltage -> HYP 复现当前 v3 中较宽的 CD/HYP 策略
v4_qab_mi Q wave abnormal -> MI 测试 MI 相关边界码对结论影响
v4_qab_sttc Q wave abnormal -> STTC 测试历史 broad STTC 设定
v4_loose_norm sinus brady/tach/arrhythmia 在无其他异常时可作为 NORM-compatible 测试 NORM 定义敏感性
v4_scored_only 只允许 Challenge official scored label 参与主映射 测试官方 scored label 子集下结论是否稳定
v4_exclude_outside_super5 评测时排除 all-zero/outside-super5-only 样本 测试大量 all-zero 对 AUROC/AUPRC 的影响

方案 C：ECGFounder 对比映射修正

方法 定位 建议
当前 keyword + max pooling 历史弱基线 保留在附录；不要称为 ECGFounder official Super5
strict manual zero-shot pooling 更干净的开箱弱基线 去掉 temporal comparison、early repol、pericarditis、short QT、device-only 等任务
150 probs -> Super5 logistic bridge 标签空间桥接 冻结 ECGFounder official head，用 PTB-XL fold 1-8 学习 150-to-5 映射
Frozen ECGFounder backbone + PTB-XL Super5 linear head 公平主对比 最推荐：fold 1-8 训练 head，fold 9 调参，fold 10 与 PN2021 外评

6. 对当前在线对抗训练的标签影响

我们的 VAE latent space 在线对抗训练是多标签任务。当前安全规则是：同一次 latent hull 组合中， 只允许 exact same multi-hot label，或者至少同 primary class 的目标中心真实样本进入同一个候选池。 这样生成的 z_adv 才能继续继承 hard label。 

z_mix = sum_i softmax(a_i) * z_i
z_adv = (1 - lambda) * z0 + lambda * z_mix
场景 当前标签策略 是否建议主线使用
same exact multi-hot latent hull 沿用原 hard multi-hot label 推荐
same primary class latent hull 沿用 primary/hard label，并做 teacher gate 或 confidence audit 可用，但要记录
cross-class latent mixing 需要 union label、soft label 或 teacher soft label 不进主线，单独消融

7. 推荐执行顺序

  1. 冻结 PTB-XL 规则，不修改 confidence_threshold=0.0，只补充 cache 命名和文档说明。
  2. 实现 PN2021 mapping config 化：v3_current、v4_strict、v4_broad_cd_hyp、v4_qab_mi、v4_loose_norm 等。
  3. 给每个版本生成 mapping hash，并写入 PN2021 eval cache metadata。
  4. 对 7 个 PN2021 center 输出标签分布表：N、每类阳性、all-zero、multi-label、unmapped SNOMED top-k。
  5. 用当前 PTB-XL baseline 和 VAE-only 在线对抗训练模型重跑 PN2021 clean AUROC/AUPRC。
  6. 如果不同映射版本下“VAE-only 在线对抗训练相对 baseline 的提升方向”稳定，再把结论写入论文主表；否则改成 sensitivity-dependent claim。
  7. ECGFounder 对比从 keyword/max pooling 迁移到 frozen backbone + Super5 linear head，keyword pooling 只放附录。

9. 建议论文表述

Because PhysioNet/CinC 2021 and PTB-XL use different diagnostic taxonomies,
we define a conservative, versioned semantic projection from PN2021 SNOMED-CT
diagnoses to PTB-XL Super5 diagnostic superclasses. Ambiguous rhythm, device,
voltage-only, and boundary morphology codes are not treated as positive
Super5 labels in the main analysis; they either suppress NORM or are reserved
for sensitivity analyses.
For ECGFounder, the official 150-label head is not a PTB-XL Super5 classifier.
Therefore, our main comparison should use a PTB-XL Super5 head trained on
frozen ECGFounder features. Heuristic 150-label pooling is reported only as an
auxiliary label-space compatibility baseline.
