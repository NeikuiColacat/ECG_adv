ECG 跨中心方法对比首轮实验建议

基于 docs/reports/archive/undated/method_cmp.md 与当前 VAE-only real-anchor LH-AT 结果整理，日期：2026-05-16。

结论：首轮不要先跑 ECG-FM / ECGFounder / SHOT / TENT 这类协议差异较大的方法。最合适先跑的是 K-shot FT + Mixup，随后跑 K-shot FT + Manifold Mixup 和 K-shot FT + SAM。

理由是它们和我们的 LH-AT 一样使用目标中心 K 条有标签样本，最公平、实现成本最低、论文审稿时也最能回答“你的方法是不是只是普通微调、普通插值或鲁棒优化”的质疑。

推荐首轮对比顺序

优先级 方法 为什么先跑 第一轮协议 预期结论价值
P1 K-shot FT + Mixup 最直接的插值增强 baseline。若 LH-AT 明显优于它，就能说明 VAE latent hull 的收益不是普通输入空间 Mixup。 K=500；Ningbo、CPSC 先跑；复用同一批 ref ids；epoch=30；mixup alpha 先试 0.2 和 0.4。 最高优先级，应该马上做。
P2 K-shot FT + Manifold Mixup 概念上最接近我们的方法：都是“隐藏/特征空间插值”。区别是我们在 ECGTwin VAE latent 中做 same-label target anchor + adversarial search。 K=500；Ningbo、CPSC；hidden layer 先选 EfficientNet 倒数第二层或 block 输出；alpha 0.2/0.4。 必须打赢或至少持平，否则 LH-AT 的贡献要重新表述。
P3 K-shot FT + SAM 回答“提升是否只是来自更平滑的极小值/泛化优化”。SAM 和我们都属于泛化增强，但不使用 ECGTwin VAE target manifold。 K=500；Ningbo、CPSC；rho 0.05 起步；AdamW 或 SGD-SAM 需固定学习率策略。 审稿友好，成本中等。
P4 Random same-label latent hull 这是我们方法内部最关键消融：去掉对抗优化，只随机或均匀组合同标签 target VAE latent。 K=500；M=20/80；lambda=0.15；不优化 a_i，只用 uniform 或 Dirichlet 权重。 证明 hard search 有独立贡献。
P5 Deep CORAL / SHOT / EATA 这些是 target-unlabeled 或 test-time adaptation，协议和 K-shot labeled 不完全一致。适合补充，不适合做第一轮主对比。 先等 P1-P4 出结果；单独声明使用目标中心无标签数据，不和 K-shot labeled 表混在一起。 作为补充表更合适。
P6 ECG-FM / ECGFounder 是强 backbone baseline，但不是同类 target-center adaptation 方法。接入成本、标签头、输入预处理和权重许可都需要额外确认。 后续做 K-shot linear probe / fine-tune；先不要阻塞当前 LH-AT 对比。 重要但不是第一优先级。

首轮执行建议

Phase 1：最小可证明对比

  • 中心：先跑 ningbo 和 cpsc_2018，因为当前 direct FT 与 LH-AT 都已经有完整结果。
  • K：先固定 K=500，复用当前 LH-AT 的 subset/ref ids，评估时继续排除这些 ref ids，避免测试集污染。
  • 方法：Direct FT、FT+Mixup、FT+Manifold Mixup、FT+SAM、Random Latent Hull、Ours LH-AT。
  • 指标：每个中心报告 held-out target AUROC/AUPRC、PN2021 7-center avg、PTB-XL fold10 保持情况。

Phase 2：扩展到四中心和 K sweep

  • 中心扩展：ningbo、chapman_shaoxing、cpsc_2018、georgia。
  • K 扩展：100 / 200 / 300 / 400 / 500。
  • 若 P1-P3 有方法接近或超过 LH-AT，再对该方法补 3 个随机种子；如果明显落后，先保留单 seed 作为主表初版。

为什么不先跑 foundation model

ECG-FM 和 ECGFounder 是强基线，但它们回答的是“换更强预训练 backbone 是否更好”。我们的当前论文主张是“在少量目标中心样本条件下，VAE target latent hull adversarial adaptation 能增强跨中心性能”。这两个问题不同。

如果先跑 foundation model，会带来新的变量：模型架构、预训练数据、输入长度、标签头、微调超参都变了。首轮最应该控制变量，只换 adaptation 方法。

下一步动作

  1. 在现有 scripts/paper/run_direct_finetune_k500_20260516.py 基础上派生一个 comparator runner，加入 --method direct|mixup|manifold_mixup|sam。
  2. 先跑 ningbo 和 cpsc_2018 的 K=500 单 seed 快速版，确认 Mixup/Manifold Mixup/SAM 是否接近 LH-AT。
  3. 若 LH-AT 仍明显领先，再扩展到四中心与 K sweep；若某个 baseline 接近 LH-AT，则优先补 seed 和超参，保证结论站得住。

一句话建议：从 K-shot FT + Mixup 开始跑；它最便宜、最公平、最能检验我们方法是否只是普通插值增强。跑完后立刻接 Manifold Mixup，这是对 LH-AT 最关键的外部对照。
