Phase 1 K-shot Baseline 对比结果

日期：2026-05-16；协议：K=500 target-center labeled adaptation，target ref ids 在 PN2021 eval 中排除；指标为 macro AUROC / macro AUPRC。

阶段结论：Mixup、Manifold Mixup、SAM 都没有追上我们的 VAE real-anchor LH-AT。更重要的是，uniform latent hull 几乎复现 optimized LH-AT 的结果，说明当前收益主要来自“目标中心真实样本 VAE latent hull + 外层训练”，而不是来自优化 convex coefficients 的 hard-search 本身。

解释

  • 普通 K-shot 方法不够：Mixup、Manifold Mixup、SAM 在两个中心都只接近 direct FT，没有获得 LH-AT 的 target-center 增益。
  • VAE latent hull 是关键：uniform latent hull 即使不优化组合权重，也几乎达到 optimized LH-AT，说明目标中心真实样本的 VAE latent hull 约束本身贡献很大。
  • hard-search 权重贡献弱：当前 optimized softmax coefficients 相比 uniform 只提升 0.01-0.16 pp，不能把主要贡献归因到 adversarial coefficient optimization。
  • 存在权衡：LH-AT / uniform hull 明显提高 target center，但 PTB-XL fold10 从 source-only 的 0.9072 / 0.7744 降到约 0.901-0.902 / 0.763，说明是 target adaptation 而不是全局无损泛化。
  • CPSC 限制：CPSC K=500 selected refs 中 MI anchor 为 0，实际 trusted hull 主要由 NORM/STTC 构成。CPSC 结果仍然强，但类别覆盖限制需要在论文中说明。
