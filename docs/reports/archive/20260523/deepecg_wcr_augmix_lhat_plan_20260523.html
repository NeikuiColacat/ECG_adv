ECG AugMix 算子可控性与 Latent-Hull 在线对抗训练组合计划

目的：评估现有 5 个 ECG corruption/augmentation 算子的 severity 是否可控，并规划把 real-anchor VAE Latent-Hull 在线对抗训练与 AugMix 风格增强做线性组合的实验路线。

日期：2026-05-23 主线：PTB-XL Super5 + PN2021 v5/v3 评估闭环 核心模型：EfficientNet1DV2, ECGFounder, DeepECG WCR 增强源：DeepECG 5 算子 + ECGTwin VAE latent hull

结论先行

可控 severity 在工程上可控

AugMix 内部 severity 为 1..10，参数按线性插值增强；PN2021-C 公开 severity 为 1..5，映射到内部 [2,4,6,8,10]。

边界 不是临床严重度标定

severity 是 benchmark 强度，不是临床/物理严格标定。每个算子内部仍有随机幅度、相位、频率或导联选择。

推荐 先做 loss-level 组合

第一轮不要直接把被 corruption 的 adversarial ECG 用 hard label 强监督。更稳的是 BCE stream loss + lambda_jsd * AugMix JSD。

当前 PN2021-C 证据应表述为：增强模型提高 corrupted ECG 上的绝对 AUPRC，但还没有稳定降低相对 self-clean drop。 例如 prompt-token v14 的 corrupted mean AUPRC 约 0.4928，baseline 为 0.4889； 但 baseline 的 self-clean AUPRC drop 仍最低。

现有 5 个 ECG 增强算子

这 5 个算子来自 DeepECG/fairseq-signals 的 ECG perturbation，实现已复制到 methods/augmix/ecg_ops.py， severity 参数映射由 methods/augmix/severity.py 统一管理。输入输出均为 torch.float32 [12, L]，当前 severity 标定基于 100Hz、per-sample z-score 后信号标准差约为 1。

算子 模拟含义 severity=1 severity=10 可控性判断 训练建议
powerline_noise 50/60Hz 工频正弦干扰，随机相位。 max_amp=0.03 max_amp=0.30 幅度上可控，但 100Hz 下 50/60Hz 有 Nyquist/aliasing 风险。 适合作为 stress test；论文里谨慎写成真实采集链路模拟。
emg_noise 逐导联高斯白噪声，近似肌电/高频噪声。 max_amp=0.02 max_amp=0.20 幅度连续随机，severity 单调增强。 最适合第一批训练增强，label-preserving 风险较低。
baseline_wander 3 个低频余弦叠加，频率 0.01..0.2Hz。 max_amp=0.05 max_amp=0.40 低频幅度可控，频率/相位随机。 很像跨设备/运动导致的域偏移，适合主组合实验。
baseline_shift 阶梯型 DC 偏移，覆盖一段时间。 max_amp=0.05, shift_ratio=0.05 max_amp=0.40, shift_ratio=0.40 代码中实际 offset 受 ±1 - U(0,max_amp) 影响，severity 更主要控制影响时长。 偏强，建议低 severity 或单独 ablation。
random_leads_masking 随机导联清零，模拟缺导联/导联失效。 mask_prob=0.05 mask_prob=0.50 导联选择离散随机，mask 概率单调可控。 高 severity 很强，更像 robustness benchmark；训练时先低强度。

PN2021-C 与 AugMix 的 severity 差别

用途 severity 范围 实际映射 说明
AugMix 训练接口 1..10 直接传入 build_op(name, severity) 更细，适合 sweep：s=2,3,5,7。
PN2021-C benchmark 1..5 1,2,3,4,5 -> 2,4,6,8,10 更像 ImageNet-C 的公开 severity 档位，不能混进 clean PN2021 平均指标。

已有 PN2021-C 证据怎么解释

正向证据

Latent-Hull 和 prompt-token 系列在 corrupted ECG 上的绝对 AUPRC 高于 baseline。当前最高档约为 0.4928，baseline 约 0.4889。

谨慎边界

baseline 的 self-clean AUPRC drop 仍最低，说明当前增强并未证明“相对抗 corruption 敏感性更低”。论文中要写成 absolute corrupted performance 提升。

corruption baseline self-clean AUPRC drop Latent-Hull self-clean AUPRC drop corrupted AUPRC baseline / LH 解释
powerline_noise 0.0010 0.0009 0.5220 / 0.5269 影响很小，更多是轻度 stress。
emg_noise 0.0036 0.0036 0.5194 / 0.5242 绝对性能提升，但 drop 几乎持平。
baseline_wander 0.0243 0.0252 0.4987 / 0.5026 更像真实域偏移，值得作为训练增强重点。
baseline_shift 0.0605 0.0626 0.4625 / 0.4652 强 stressor，训练强度要保守。
random_leads_masking 0.0811 0.0833 0.4419 / 0.4445 最强 stressor，先作为评估，不建议高强度训练混入。

组合思路：不要先混波形，先混损失

对当前 Super5 主线，最稳的第一版不是把 adversarial ECG 和 AugMix ECG 直接拼接成一个更大的强监督样本池， 而是在原有在线 AT 的 BCE 训练流上，加一个 AugMix 一致性分支。这样不改变 source/target/adv stream 的采样比例， 也避免 corruption 后的 VAE decoded adversarial ECG 被硬标签过度监督。 

L = L_stream_bce
  + lambda_jsd * JSD(f(x), f(A1(x)), f(A2(x)))
  + lambda_src * || f_theta(x_source) - f_theta0(x_source) ||^2
  + lambda_anchor * || theta - theta_init ||^2

其中 L_stream_bce 沿用现有 mixed streams：PTB-XL source、target real、roundtrip、Latent-Hull adv buffer。 A1/A2 是两次独立 ECG AugMix corruption；JSD 用现有多标签 Bernoulli 版本。

1. clean batch从现有 source 或 target real stream 取 ECG
2. AugMix A1/A25 算子随机 chain，severity 可控
3. model logitsclean, aug1, aug2 三路 forward
4. BCE + JSDclean 监督，aug 分支一致性
5. PN2021-C eval看 absolute 与 self-clean drop

推荐实验矩阵

阶段 实验组 训练数据/损失 目标问题 建议参数

1 AugMix-only(source) PTB-XL source clean BCE + source AugMix JSD。 先测 corruption consistency 是否伤源域。 severity=3, width=3, depth=-1, lambda_jsd=4,8,12。

3 LHAT + AugMix(source+target_real) source 和 target real 都做 JSD，不对 adv 做 JSD。 看 target-center real anchors 是否通过 corruption consistency 更稳。 target_real 只用低/中 severity：2..3。
4 LHAT + latent AugMix inject adv 把 z_adv 作为 AugMix latent chain 注入，其他 chain 来自 time-domain AugMix 后 VAE encode。 测试“对抗方向”和“采集噪声方向”能否在 VAE manifold 中协同。 使用已有 inject_latents=[z_adv] 能力；先离线 buffer，不直接在线训练。

EfficientNet1DV2 侧怎么改

EfficientNet1DV2 是首选实现对象，因为它的在线 AT runner 仍在 waveform 路径上训练，能直接对 [12, 1000] ECG 做 AugMix，再 forward 到 Super5 logits。

代码改造点

  1. 在 scripts/pgd_cross_center/synth_online_at_super5.py 增加 CLI： --augmix_enable, --augmix_streams source,target_real, --augmix_severity, --augmix_width, --augmix_depth, --augmix_alpha, --augmix_jsd_weight。
  2. mixed streams 构造时保留 stream id。当前 source/target_real/adv 都会进入同一个 sampler， 如果不保留 stream id，就没法只对 source 或 target real 做 AugMix JSD。
  3. 在 train step 中，对于被允许的 stream，生成 aug1, aug2，做三路 forward， 加 jsd_multilabel(logits_clean, logits_aug1, logits_aug2)。
  4. epoch log 记录 augmix_jsd_loss、augmix_stream_count、severity、 width、depth，避免后续报告追不回配置。

ECGFounder 与 DeepECG WCR 侧注意点

ECGFounder frozen-head

当前 ECGFounder VAE-only runner 训练的是预提取 feature：source_x/target_x/adv_x。 如果直接套 AugMixECGDataset，得到的是 feature-level 增强，不是真正 ECG corruption。

可行做法：新增 paired corruption feature cache： clean ECG -> AugMix A1/A2 -> frozen ECGFounder encoder -> feature_clean/feature_aug1/feature_aug2 -> head JSD。

DeepECG WCR

WCR 输入协议更接近 DeepECG：[12,2500]，Transformer encoder feature 维度为 768。 若做同类路线，应先补 WCR frozen encoder -> Linear(768,5) Super5 head，再接 AugMix/LHAT。

WCR 90M 参数，Latent-Hull 内层 PGD 会比 EfficientNet 和 ECGFounder 更慢。先做 feature-cache linear probe 和小 batch smoke。

ECGFounder 的输入是 12 x 5000，DeepECG WCR 是 12 x 2500。 AugMix severity 当前按 100Hz/1000 点标定。跨模型复用时，要么先在 100Hz canonical ECG 上腐蚀再转模型输入， 要么为 250Hz/500Hz 单独重标定 severity。

评估与判定标准

指标层 必须报告 判定
clean PN2021 4-center 与 7-center macro AUROC/AUPRC，ref ids 排除。 不能为了 robustness 明显牺牲 clean AUPRC。
PTB-XL source fold10 macro AUROC/AUPRC。 防止 AugMix JSD 导致 source domain collapse。
PN2021-C absolute corrupted mean AUROC/AUPRC，per-corruption severity 曲线。 这是当前增强模型最稳定的正向证据。
PN2021-C self-clean drop 每个模型用自己的 clean JSON 计算 drop。 只有 drop 下降才能声称 relative robustness 改善。
per-center/per-class ningbo、chapman_shaoxing、cpsc_2018、georgia；CD/HYP/MI/NORM/STTC。 定位收益来自噪声鲁棒性还是某个中心/类别偏移。

最小可执行路线

  1. 先在 EfficientNet1DV2 runner 加 AugMix JSD 分支，只启用 source stream。
  2. 跑单中心 smoke：推荐 ningbo 或 cpsc_2018，epochs=3..5 检查 loss、显存、输出字段。
  3. 跑完整 LHAT + AugMix(source)：四中心，单 seed，severity=3，lambda_jsd=4。
  4. 对比 LHAT-only、AugMix-only、LHAT+AugMix 的 clean PN2021 与 PN2021-C。
  5. 若 PTB-XL 不掉且 PN2021-C absolute 上升，再 sweep lambda_jsd=8,12 和 severity=2,5。
  6. 最后再考虑 target_real stream JSD 和 latent-level inject_latents=[z_adv] 方案。
建议论文口径：AugMix 算子提供可控采集扰动，Latent-Hull 提供目标中心真实 anchor 附近的 on-manifold 对抗边界样本。 二者组合要证明的是“采集噪声鲁棒性”和“跨中心判别边界适应”是否互补。
