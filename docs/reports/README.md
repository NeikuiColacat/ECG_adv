# Reports

This directory stores archived HTML/Markdown reports that are useful for
inspection, handoff, or presentation but are not the canonical source of
experiment truth.

Use these report files as supporting context. For current trusted facts, prefer:

- `configs/active_evidence_registry.yaml`
- `configs/active_scripts.yaml`
- `docs/pipelines/`

Archived reports are grouped by date under `archive/YYYYMMDD/`.
